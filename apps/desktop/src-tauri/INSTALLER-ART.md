# Installer artwork

All installer images use the Design C Lux palette and are generated by one script:

```bash
pip install Pillow
python3 scripts/generate-installer-art.py
```

| File | Used by | Size |
| --- | --- | --- |
| `dmg-background.png` | macOS DMG window (`bundle.macOS.dmg.background`) | 660×400 PNG |
| `installer/nsis-sidebar.bmp` | Windows `.exe` welcome and finish pages (`bundle.windows.nsis.sidebarImage`) | 164×314 BMP |
| `installer/nsis-header.bmp` | Windows `.exe` inner-page header (`bundle.windows.nsis.headerImage`) | 150×57 BMP |
| `installer/wix-banner.bmp` | Windows `.msi` top banner (`bundle.windows.wix.bannerPath`) | 493×58 BMP |
| `installer/wix-dialog.bmp` | Windows `.msi` welcome and finish background (`bundle.windows.wix.dialogImagePath`) | 493×312 BMP |

The BMPs are 24-bit, as NSIS and WiX require. Paths in `tauri.conf.json` are relative to this directory.

The DMG icon slots sit at `appPosition` (180, 220) and `applicationFolderPosition` (480, 220). If those change in `tauri.conf.json`, update the script to match.

The WiX dialog draws its welcome text right of x=164, and the NSIS header and WiX banner draw page titles on their left side, so the mark stays out of those areas.
