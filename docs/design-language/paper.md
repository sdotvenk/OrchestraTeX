# Design A · Paper

Warm project chrome frames a light code canvas and white PDF. Weight comes from typography, dividers and alignment. The [original five screens](../design-a/README.md) are the approved baseline; the docked session, tab and muted cards are extensions for evaluation.

| Role | Material |
| --- | --- |
| Window, project tree | Putty #E7E2D7 and pale linen #EEEBE2 |
| Source, manuscript | Warm white #FCFBF8 and page white #FFFFFF |
| Rail, terminal, text | Ink #242521 |
| Primary action | Signal orange #FF6332 |
| Awaiting permission, usage | Wheat #E8D7AE and gray-green #D8DCCC |
| Raised controls | 0.65 px warm edge, 1 px offset; reserve elevation for actionable or inspectable groups |

Use sentence-case sans for commands, mono for code, paths and measurements, and the manuscript font for proof. Keep the Score mark small in the toolbar. A compact permission can interrupt the transcript; quiet tool activity remains inline. Preserve visual hierarchy when adjacent surfaces have similar hues by using spacing, an edge and a clear heading.
