# Design B · Studio

Color identifies whole working regions. Mint grounds navigation, lavender holds window chrome and the preview stage, and plum anchors the rail. The source and printed page give the eye a quiet reading area.

| Role | Material |
| --- | --- |
| Window, file tree | Lavender #B2AEEF and mint #C0D9CE |
| Source, manuscript | Cool white #FBFAFF and page white #FFFFFF |
| Rail, structural edge | Plum #242332 and deep violet #33313F |
| Primary action | Coral #FF8468 |
| Awaiting permission, usage | Amber #F5CE6A and periwinkle #C7C5FF |
| Raised controls | 1.35 px ink outline, about 2.5 px hard offset; share the same light direction throughout |

Carry color through stationary surfaces. Raise a selected thread, permission request or composer; keep file rows and running text flat. Use condensed headings for decisions and tabular numerals for comparable usage values. Use compact sans for the rest of the UI and mono for commands. A state label and the actual command remain visible independently of hue.
